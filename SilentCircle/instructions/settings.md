# What's Included

## General Settings

- Toggle for enabling/disabling Silent Circle.
- Option to switch between silent mode and vibration.

## Notifications

- Toggle for notifications when entering/exiting geofences.

## Distance Unit

- Picker to toggle between kilometers and miles.
- Uses a SegmentedPickerStyle for a simple UI.
## Privacy & Permissions

- Buttons to manage location and notification permissions via system settings.
## About

- App version display.
- Button for contacting support.
